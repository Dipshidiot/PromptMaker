# PromptMaker

A prompt creator for creators.

## How to Use

1. Load [CORE_RULES.md](CORE_RULES.md) into your AI tool.
2. Choose a style pack (or say **Chaos Agent**).
3. Describe your subject.
4. Get three copy-ready prompts — Realistic, Stylized, Full Crazy.
5. Copy the one you want. Paste. Generate.

## Adding a New Style Pack

Copy [STYLE_PACK_TEMPLATE.md](STYLE_PACK_TEMPLATE.md), fill in the 7 sections, save as `style_packs/06_[name].md`. Done.
