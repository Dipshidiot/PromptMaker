# STYLE PACK: Vaporwave Dream

## Core Aesthetic
A nostalgia trip that never existed. The aesthetics of 1980s–90s consumer culture filtered through internet surrealism and longing. Marble busts beside Windows 95 desktops. Endless grids stretching to a synthetic horizon. Something beautiful that is also slightly sad and you're not sure why.

## Lighting Behavior
Gradient ambient light — pink above, purple below, with teal or cyan accents. No defined light source. Everything glows slightly from within. Reflective grid floors multiply the color. The sky is always synthwave sunset, even indoors.

## Color Behavior
Hot pink, lavender purple, electric teal, soft coral, chrome white. High saturation but dreamy — not harsh. Colors bleed into each other. Gradients dominate. The palette is impossible and entirely coherent.

## Texture Behavior
Smooth gloss on subjects. CRT scanline overlay optional. Pixelation artifacts from low-res retro elements. Grid lines on floor and horizon. Marble texture on classical elements. VHS tracking distortion on edges. Chrome reflections everywhere.

## Motion Behavior
Slow drift. The grid scrolls forward gently. Palm trees sway in a non-existent breeze. Dolphins leap through the air because this is that kind of place. Classical busts rotate slowly. Time is a circle here.

## Caption Tone
Nostalgic, slightly ironic, dreamy. Japanese text mixed with English optional. Feels like a screensaver caption or a fortune cookie written by an algorithm.

- "FEEL THE BEAT OF THE PAST FUTURE"
- "悲しみ / sadness.exe has stopped responding"

## Transformation Rules

### Realistic
High-quality render of a vaporwave environment — correct colors, grid floor, sunset gradient sky. Classical elements present but rendered cleanly. Feels like professional concept art or a game environment screenshot.

### Stylized
More abstracted and surreal. Elements float freely. Classical statues partially pixelated. Windows 95 interfaces stack in the background. Dolphins definitely present. Text artifacts visible. The CRT scanlines are doing a lot of work.

### Full Crazy
Reality is the screensaver now. The grid extends infinitely in all directions including up. Multiple classical busts orbit a floating Windows 95 dialog box. Everything is simultaneously pink and purple. Dolphins in space. The sad music is visible as pink soundwaves. A2AESTHETICS.EXE has encountered an error and it is beautiful.

## Example Outputs
- **Realistic:** A marble bust of Caesar on a chrome pedestal, infinite pink-purple grid floor extending to a gradient sunset horizon, palm tree silhouettes at the edges, clean render quality.
- **Stylized:** Same bust now partially pixelated, surrounded by floating 3D geometric shapes, Windows 95 dialog boxes as background elements, CRT scanlines visible, neon purple-pink gradient sky, Japanese text floating as ambient elements.
- **Full Crazy:** The entire image is a cascading pink vaporwave explosion — Caesar bust multiplied six times, dolphins leaping through the desktop background, the grid is now the sky and the sky is the floor, every element outlined in cyan, the sadness.exe dialog box is the largest thing in frame.
