# TEXT PLACEMENT: Split (Top + Bottom)

## Identity
Two distinct text blocks: one anchored at the top, one at the bottom. The image occupies the middle ground between them. The native format of the classic meme: setup above, punchline below. Also used for dialogue, before/after framing, and two-part declarations.

## Positioning Rules

| Property | Value |
|----------|-------|
| **Top block anchor** | Top edge, 3–6% margin |
| **Bottom block anchor** | Bottom edge, 3–6% margin |
| **Both blocks** | Center-aligned horizontally |
| **Text block width** | 85–95% of image width each |
| **Middle zone** | Must remain clear — minimum 40% of image height unoccupied by text |
| **Visual balance** | Top and bottom blocks should be visually balanced in weight |

## Use Cases
- Classic meme setup/punchline format
- Dialogue or call-and-response (character A top, character B bottom)
- Before/after framing
- Two-part declarations or contrasts ("Expected: / Reality:")
- Propaganda Parody poster format (header + slogan)

## Style + Texture Compatibility

| Works Well | Use With Caution |
|-----------|-----------------|
| Bold Meme Block (native) | Vintage Noir (works if text is short) |
| Corporate Parody | Soft Wholesome (may feel too structured) |
| Comic Halftone texture | Chaotic Burst (may overwhelm the image) |

## Behavior Across Variation Levels

### Realistic
Both text blocks are clean and legible. Consistent font, size, and treatment between top and bottom. The image between them is fully visible and forms the visual bridge. Classic two-part structure maintained.

### Stylized
Top and bottom blocks may differ in visual treatment — same font family but different weight or size to create hierarchy. Top is the question; bottom is the answer. Visual tension between the two blocks is intentional.

### Full Crazy
Top and bottom text blocks compete. Different fonts, different colors, different sizes. The middle image is under siege from two directions. The top setup is huge; the punchline at the bottom is even bigger. The image in the middle is holding on for its life.

## Avoid When
- The image is very tall (the middle zone becomes too large; use Top + Bottom individually)
- The image subject is centered and critical (it will sit directly between two text blocks — consider if this is intentional)
- More than 2 lines needed at either position (use Center or a dedicated layout instead)
