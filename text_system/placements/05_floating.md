# TEXT PLACEMENT: Floating (Style-Dependent)

## Identity
Text exists without a fixed anchor. It is positioned compositionally — placed where the image's own geometry, negative space, or visual flow creates a natural home for it. The text is discovered within the image rather than imposed upon it. Only available when the style pack supports it.

## Positioning Rules

| Property | Value |
|----------|-------|
| **Vertical anchor** | None fixed — determined by image composition |
| **Horizontal position** | None fixed — determined by image composition |
| **Natural placement zones** | Sky, wall, floor, side negative space, object surfaces |
| **Rotation** | Permitted — text may follow image geometry |
| **Margin from edge** | Minimum 5% from any edge |
| **Contrast handling** | Text color/treatment must create legibility against its background zone |

## Style Pack Eligibility

| Style Pack | Floating Behavior |
|------------|------------------|
| Neon Noir | Floats on walls, signs, reflective surfaces |
| Vaporwave Dream | Floats in the grid, in the sky, mid-space |
| Cyberpunk Chrome | Floats as HUD element, holographic overlay |
| Cosmic Horror | Floats in the void, mid-atmosphere |
| Chaotic Burst styling | Floats everywhere simultaneously |
| Dark Academia | Floats on pages, scrolls, chalkboards within the image |

**Style packs not eligible for Floating:** Meme Lord, Luxury Brand, Retro Vintage (these require structured placement for their aesthetic to work).

**Text styles not eligible for Floating:** Corporate Parody (professional precision requires anchored placement — see Style × Placement matrix).

## Use Cases
- When the image has natural text-ready surfaces (signs, walls, sky, floors)
- When the text is part of the world of the image rather than a caption on top of it
- Holographic or in-world UI elements (Cyberpunk, Vaporwave)
- Poetry or lyric placement in atmospheric images
- When breaking the Top/Center/Bottom grid creates a better image

## Behavior Across Variation Levels

### Realistic
Text is placed in a single natural zone of the image — the clearest, most compositionally justified location. Behaves as if it belongs in the photograph or illustration. No rotation unless the image geometry specifically calls for it.

### Stylized
Text may occupy a surface within the image world (a sign, a wall, a page). Placement is a design decision. Text may be slightly angled to follow perspective. The text and image feel like a unified artwork.

### Full Crazy
Text is everywhere and nowhere. Multiple floating text elements at different sizes, angles, and colors. Some are in-world; some are from outside; some are arguing with each other. The composition holds because chaos has its own gravity.

## Avoid When
- The image has no clear negative space or readable surfaces
- Legibility cannot be guaranteed without reverting to a fixed placement
- The style pack explicitly does not support floating (check eligibility table above)
