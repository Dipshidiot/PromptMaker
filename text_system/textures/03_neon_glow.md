# TEXT TEXTURE: Neon Glow

## Identity
Bioluminescent bloom. The text emits colored light rather than simply existing as a shape. Soft halo extends beyond the letterforms. The glow interacts with surrounding elements — casting light on surfaces, bleeding into shadows. Text that is also a light source.

## Visual Properties

| Property | Value |
|----------|-------|
| **Surface quality** | Smooth core with soft radial bloom extending outward |
| **Glow radius** | 15–40% of letter height |
| **Core color** | Bright, highly saturated |
| **Glow color** | Same hue, reduced brightness, increased spread |
| **Outer edge** | Feathered to transparency |
| **Ambient interaction** | Optional: glow tints surrounding image elements |

## Best Used With
- Neon Noir (native — the glow IS the aesthetic)
- Cyberpunk Chrome (HUD and interface energy)
- Vaporwave Dream (synthwave luminescence)
- Cosmic Horror (bioluminescent dread)

## Avoid With
- Cottagecore (artificial light breaks the pastoral)
- Retro Vintage (anachronistic light source)
- Soft Wholesome styling (glow is too intense for the tone)
- Toy Box (craft materials don't glow)

## Behavior Across Variation Levels

### Realistic
Single-color neon glow — tight radius, high-quality bloom. Feels like practical neon tubing or an LED strip. The glow behaves physically, illuminating nearby surfaces.

### Stylized
Double or multi-color glow — core in one color, outer bloom in a complementary or contrasting hue. Glow radius expanded. Interaction with surrounding environment exaggerated. Feels like a concert poster.

### Full Crazy
The glow has taken over. Letters are burning pillars of light. Multiple overlapping glows in different colors create interference patterns. The surrounding image is tinted and bleached by the brightness. The text is no longer type — it is an event.
